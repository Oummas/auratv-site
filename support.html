Questions fréquentes

Comment ajouter une source ?

Au premier lancement, ou dans Réglages, choisissez d'ajouter une source puis saisissez les informations données par votre fournisseur : identifiants Xtream ou lien de playlist M3U. AuraTV ne fournit aucune source.

Comment restaurer un achat ?

Ouvrez Réglages puis touchez « Restaurer mes achats ». Utilisez le même compte Apple que lors de l'achat.

Comment gérer ou résilier mon abonnement ?

L'abonnement AuraTV+ est géré par Apple. Dans Réglages de l'iPhone, touchez votre nom puis Abonnements, ou utilisez « Gérer l'abonnement » dans l'application. La résiliation prend effet à la fin de la période en cours.

Le contrôle parental et le code oublié

Le contenu pour adultes est masqué d'office, partout dans l'app. Le code à 4 chiffres est demandé pour l'afficher, désactiver le filtre ou changer le code. Si vous l'avez oublié, écrivez-nous.

L'IA et ma confidentialité

L'IA n'est utilisée que pour la recherche en langage naturel et quelques aides, et uniquement si vous les utilisez. Il n'y a ni compte ni traçage publicitaire. Le détail est dans la politique de confidentialité.
